# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-02-07

### Added
- Initial release
- Jina Reader API integration (URL to markdown/HTML/text)
- Jina Search API integration (web search with structured results)
- Durable caching with configurable TTL
- Usage tracking per operation and user
- Class-based `JinaAI` client
- Retry logic with exponential backoff
- CSS selector targeting (target/remove/waitFor)
- ReaderLM v2 support
- Demo app with URL Reader, Web Search, and Usage Dashboard
